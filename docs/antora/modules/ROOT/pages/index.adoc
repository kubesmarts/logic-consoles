= Authoring Console

The Authoring Console is the browser interface for Logic Operator. Administrators configure the cluster platform and workflow runtimes. Authors use those runtimes to publish versioned workflow definitions, execute them through the gateway, and inspect their history.

* xref:getting-started.adoc[Connect and run your first workflow] on the operator's KIND demo.
* xref:platform-runtime.adoc[Set up the platform and runtime] on a cluster where the operator is already installed.
* xref:author-publish.adoc[Create a workflow from an example] and publish it to a runtime.
* xref:run-history.adoc[Inspect a deployed version] and follow a run through to its result.

These pages describe the development branch. Open *Compatibility* in the console to see its component baseline and available observations for your cluster.
